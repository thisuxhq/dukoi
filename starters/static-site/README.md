# static-site

A one-page site in plain HTML and CSS. There’s no build step and no `package.json`, so Dukoi serves the folder as it is.

## Make it yours

Edit `index.html`: change the name, the sentence and the links. Then run:

```bash
dukoi deploy
```

Add more pages as `.html` files next to `index.html`, and pictures in the same folder.
