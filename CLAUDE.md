# DroidHost

DroidHost turns old Android phones into app servers. Start with `docs/README.md`.

## Android work

Use Google's Android CLI (`android`) for every Android task it supports: `android create`, `android run`, `android install`, `android screen capture`, `android layout`, `android emulator`, `android sdk` and `android docs`.

Use `adb` only where `android` has no command, such as `adb shell input` for taps, `kill`, `reboot` and `device_config`. See `docs/android-cli.md`.

## Writing

Follow `docs/writing-style.md` and `docs/dx-principles.md`: plain words, simple solutions, errors that say what to do.
